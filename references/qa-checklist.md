# 交付前自检清单

生成后先跑 `python scripts/preview.py out.pptx`，再按本表核对。
报告里不达标就别交付，回去改内容或参数，不要靠手调形状。

## 硬指标（必须全绿）

| 项 | 要求 | 报告里的位置 |
|---|---|---|
| 首行字顶 | 内容页取值集合应为 `{41.1, 41.5, 41.9, 42.0}` 或 `{42.0}`；出现 45 以上或 35 以下即为错位 | `首行字顶取值:` |
| 越界 | `0` | `越界/贴边行:` |
| 切换效果 | `无（符合要求）` | `切换效果页:` |
| 答案色块起始线 | 只有一个数值（默认 `2.314`）；出现多个值说明垂直居中没去掉 | `色块 E9FFFF:` |
| 动画页数 | = 红字母数 + 答案块数；比这个少说明漏加 | `飞入动画页数:` |
| 页数 | 与内容量相符（选择题 N 页 + 答案页按需拆） | `页数:` |

## 视觉抽查（至少看 4 张）

用 `_preview/sNN.png` 看：

1. **一页选择题**：序号在、「（　）」里有一个红色字母、字母与文字齐平、选项没被挤出页面。
2. **一页材料题**：材料与问题之间几乎没有空隙（2pt），问题加粗，末行没有孤字/孤标点。
3. **一页答案页**：问题重印在上、色块紧接、色块完整包住文字、无溢出。
4. **一页最长内容**：行尾排满、右侧没有大段空白、底部未贴边。

## 常见不达标与对应改法

| 症状 | 改哪里 |
|---|---|
| 某页首行偏高/偏低 | 是否混用了 `TOP` 与 `APP_TOP`；是否又加了垂直居中 |
| 色块起始线不统一 | `build()` 里的 `q_reserve` 预扫描被绕过（比如手工插了 reading 页） |
| 行尾只剩 2—3 字 | 断行宽度系数 `0.992` 太小，或字距压缩阈值 `0.945` 太严 |
| 「（4分）」单独一行 | `tokenize` 的不可拆规则没覆盖该写法 |
| 选项右侧溢出 | 该选项没走 `pack_opts` 的折行分支 |
| 答案字母偏上 4—5pt | 独立文本框的行距没设成 1.5 倍 |
| 表格右边被裁 | 表格总宽 > 11.6 in 或列数 × 列宽超版心 |
| 字体没生效 | 缺 `a:ea` 的 `typeface`（中文必须同时设 latin/ea/cs） |

## 交付话术

交付时说明三件事：页数与页面结构、两处必要偏差（若有）、文件路径。
偏差只允许是「材料过长拆页」「选择题字号下探」两类，其余都算缺陷。
